# SOC Stand (Vagrant + Ansible)

Автоматизированный стенд из 3 виртуальных машин для тестирования SOC-инструментов и защиты контейнеров. Развертывание, настройка и проверка происходят одной командой.

## Стек технологий
- **Инфраструктура:** Vagrant, VirtualBox (7.2+)
- **Контейнеризация:** Docker, Docker Registry (TLS)
- **Безопасность (Defense in Depth):** Cosign (подписи), OPA (авторизация), AppArmor (изоляция)
- **Мониторинг и логи:** Falco, Rsyslog

## Требования
- Windows (10/11)
- VirtualBox 7.2+
- Vagrant 2.4+
- WSL 2 + Ubuntu
- В Ubuntu должен быть установлен Ansible: `sudo apt install ansible`

## Запуск
Из терминала WSL в папке проекта выполните:
```bash
chmod +x deploy.sh
./deploy.sh
```
Скрипт автоматически установит нужные Ansible-коллекции, поднимет 3 виртуальные машины, настроит на них всё ПО и прогонит финальные тесты.

## Архитектура и рубежи защиты
- **VM `docker`** — основная машина для запуска контейнеров.
- **VM `docker_registry`** — приватный реестр образов с поддержкой TLS.
- **VM `storage`** — централизованный сбор логов.

**Рубежи защиты:**
1. **Cosign** — блокирует запуск неподписанных образов через перехватчик.
2. **OPA (Open Policy Agent)** — блокирует небезопасные флаги (`latest`, `--privileged`, `root`) и опасные capabilities (например, `SYS_ADMIN`), используя белый список.
3. **AppArmor** — блокирует опасные действия внутри контейнера (чтение `/etc/shadow`, `mknod`).
4. **Falco + Rsyslog** — детектирование подозрительной активности (например, чтение чувствительных файлов) и отправка логов на VM `storage`.
